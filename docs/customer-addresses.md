# Customer primary address and checkout choice

`/account` > « Миний мэдээлэл » includes a « Үндсэн хаяг » section. Customers can add, edit and reload one primary address (Ulaanbaatar, district, khoroo, detailed address and optional instructions). Name and phone remain in the existing profile fields.

Checkout offers « Үндсэн хаягаар хүргүүлэх » and « Өөр хаягаар хүргүүлэх ». The primary option is disabled until an address is configured and links to the account page. The selected primary location is read-only in checkout; name/phone can still be supplied for the recipient. An alternative delivery location is entered independently and never changes the primary address. The delivery choice persists after saving and refresh. A primary selection resolves the latest primary location when checkout reloads. Previously saved delivery addresses remain available as the alternative choice and are not automatically promoted to primary addresses.

When switching options before saving, the in-progress alternative form is retained within the mounted checkout page. Only the last saved delivery address is persisted, not a multi-address book. If a customer saves an alternative after a primary selection, the primary address remains intact.

Migration `20261030005953_customer_primary_addresses.sql` is applied to the shared Meiro database. It creates `customer_primary_addresses` and adds `address_source` to `customer_delivery_addresses`; existing data is preserved. Primary addresses permit only owner SELECT/INSERT and updates to location fields. Anonymous access and client-side owner changes are denied. No data was copied between accounts; test changes in the shared database were rolled back. Do not push all pending migrations (strict admin MFA is still a separate rollout).
